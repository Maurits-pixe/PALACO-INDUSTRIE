# BOTERHAM First Pilot — Definition of Done

- Every transaction is traceable in BOTERHAM.
- No balance can be changed by direct database mutation.
- Wallet profiles work and changes are historically traceable.
- M.C. reward and merchandise redemption work end-to-end in sandbox/pilot.
- M.C.7 has independent rules and bookkeeping.
- HOTSPOT can be approved, paused and ended/revoked.
- Privacy, security, support and incident documents exist.
- Test results, risks and open decisions are visible.
- Production remains blocked until formal legal, security and operational approval.
