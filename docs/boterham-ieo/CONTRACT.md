# I.E.O. Registry Contract v0.1.0

I.W.K. = Interstalair Wissel Kantoor.
I.E.O. = Interstalair Exchange Office.

The I.E.O. registry records:
- currency identity and version
- issuer/creator and Citadel/WORLD scope
- jurisdiction
- supply policy
- permitted uses
- exchange rules
- provenance
- authorization
- status
- suspension/revocation

The registry is not by itself proof that an exchange or financial service is legally authorized.
