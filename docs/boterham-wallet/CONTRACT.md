# BOTERHAM Wallet Contract v0.1.0

A wallet belongs to a Citadel identity and may contain separately classified balances.

## Owner profiles
- PHILANTROOP — donation/community/social goals
- MESCENICAS — culture, creation, art and special projects
- MISANTROOP — personal spending
- BLANCO — owner-defined destination, for example an IBAN or another permitted destination

Phone/e-mail association is optional and is not itself a financial authorization.

## Separation
Identity, balance, spending policy, destination, authorization and recovery data are separate concerns.

The wallet MUST distinguish:
- internal/promotional balance
- external/blockchain asset
- payment-rail reference
- destination data

No bank-account linkage is required for ordinary PALACO use unless a particular function legally or operationally requires it.
