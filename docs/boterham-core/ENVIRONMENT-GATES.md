# BOTERHAM Environment Gates

## SANDBOX
Test assets only. No production custody, public issuance or external exchange.

## PILOT
Restricted identities, approved HOTSPOTs, bounded limits, monitoring and incident handling.

## PRODUCTION
Requires:
- legal classification
- required authorization/partnering
- security review
- operational controls
- privacy controls
- rollback/revocation procedures
- evidence-backed release approval

A software deployment alone never transitions an instrument to production.
