# BOTERHAM HOTSPOT Contract v0.1.0

A HOTSPOT is a contracted commercial participant.

Required controls:
- operator identity
- contract and authorization
- supported instruments
- balance/issuance limits
- start and end time
- pause/revoke state
- transaction/audit linkage
- complaint and incident route

QR/web flows are the first interaction target. Bluetooth requires explicit consent and secure pairing. Goldthooth is a later, separately reviewed distribution layer.

Proximity, device possession or contact discovery MUST NOT grant monetary authority.
